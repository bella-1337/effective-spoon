LiteLLM Stack Architecture

CPU semantic routing, GPU embeddings, and operational telemetry in one deployment view

Request paths

  • • Chat: Traefik -> Envoy -> Router -> LiteLLM
  • • Automatic routing uses model vllm-sr/auto
  • • BGE-M3 embeddings remain a separate GPU service

Observability

  • • Prometheus scrapes Router and metrics-only Envoy
  • • Alloy ships service logs to Loki
  • • Grafana provisions dashboard and alerts

Maintenance

  • • Nightly scans cover BGE-M3, Router, and Envoy
  • • Running image digests are scanned fail closed
  • • Upgrade verification checks both scrape targets

Development semantic routing is internal-only; metrics and logs contain no prompt content.
