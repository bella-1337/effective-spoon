LiteLLM Coding Request Flow

A coding prompt is classified by D3-mini and completed by the model assigned to its tier.

Main path

  • • Client sends coding-router
  • • LiteLLM calls D3-mini
  • • Tier selects the completion model

Tier policy

  • • SIMPLE/MEDIUM -> gpt-4o-mini
  • • COMPLEX/REASONING -> gpt-4o
  • • 15 second classifier timeout

Failure behavior

  • • Classifier errors are observable
  • • Fallback is gpt-4o
  • • No local routing proxy

Clients use the normal LiteLLM hostname and credentials; the D3 credential is service-to-service only.
