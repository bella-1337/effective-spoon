LiteLLM Routed Request Flow

The synchronous inference path plus asynchronous metrics, logs, dashboards, and alerts

Inference

  • • Client sends model vllm-sr/auto
  • • Envoy calls the CPU semantic router
  • • LiteLLM dispatches the selected alias

Metrics

  • • Router exports decisions and latency on :9190
  • • Envoy exposes only /stats/prometheus on :9901
  • • Grafana evaluates health, error, and latency alerts

Logs

  • • Router and Envoy write container logs
  • • Alloy forwards those streams to Loki
  • • Operators investigate them in Grafana Explore

Telemetry is asynchronous and never changes the fail-closed request order.
