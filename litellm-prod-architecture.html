LiteLLM Production Architecture

Stable production serving with PII controls, isolated state, managed providers, tools, and observability

Serving path

  • • Clients enter through Traefik over TLS
  • • Presidio enforces PII policy before model access
  • • LiteLLM routes production traffic to managed providers

Production isolation

  • • Stable LiteLLM image
  • • Dedicated litellm_prod PostgreSQL database
  • • No development-only local model or vector-store dependencies

Operations

  • • SearXNG and Xberg provide approved tools
  • • Prometheus records gateway metrics
  • • Alloy, Loki, and Grafana provide log visibility
