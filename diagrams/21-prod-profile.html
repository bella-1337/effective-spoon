LiteLLM production profile

Stable production serving with PII controls, isolated state, the configured provider, tools, and default observability

Request path

  • • Clients reach litellm-prod only through Traefik on the production hostname
  • • The eu-data-protection policy applies Presidio before and after every model call
  • • coding-router asks the remote D3-mini host for a tier, then calls OpenAI

State and telemetry

  • • litellm_prod keeps keys, budgets, and spend without prompt content
  • • Prometheus scrapes metrics; OpenSearch stores logs, traces, and usage copies
  • • Langfuse and Grafana are optional profiles, not part of the default path

Production limits

  • • No Qdrant cache, pgvector store, or BGE-M3 embeddings in production
  • • Xberg reaches the Internet only through the Squid allowlist
  • • The Chat UI is disabled; the demo profile seeds data only when explicitly enabled
