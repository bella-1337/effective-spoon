Docker network boundaries

Each Compose network is a trust zone; only Traefik publishes host ports

Ingress

  • • Only Traefik publishes host ports 80 and 443
  • • edge members are reachable only through a Traefik host rule
  • • SearXNG, databases, and telemetry have no route from clients

Isolation

  • • Xberg sits alone on xberg-sandbox with LiteLLM and its proxies
  • • Its outbound HTTPS goes through Squid and its DNS through an allowlist-only resolver
  • • opensearch-certs runs with no network at all

Docker socket

  • • Traefik, Alloy, and the image scanner never mount the socket
  • • Each reaches Docker through its own socket proxy on a dedicated network
  • • The proxies allow read-only GET calls; POST is disabled
