Observability pipeline (default)

Logs, metrics, traces, and LiteLLM usage converge in OpenSearch; operators read them through Dashboards

Ingest paths

  • • Alloy ships container logs over OTLP to Data Prepper
  • • LiteLLM exports content-free spans to Data Prepper Trace Analytics
  • • The bridge mirrors Prometheus series and non-content PostgreSQL rows every minute

Stores

  • • OpenSearch: logs, mirrored metrics, alert state, usage copies, audit log
  • • Prometheus stays the metrics source of truth and a PPL direct-query source
  • • LiteLLM PostgreSQL stays the system of record for spend and identity

Access and alerts

  • • OpenSearch security roles and tenants restrict each user
  • • One alerting monitor per Grafana rule, plus staleness monitors
  • • Set OPENSEARCH_ALERT_CHANNEL_ID or alerts are visible only in the UI
