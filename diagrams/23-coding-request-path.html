Coding request path

A coding prompt is classified by D3-mini and completed by the model assigned to its tier

Request path

  • • The client calls model coding-router through Traefik
  • • LiteLLM authenticates, applies budgets and guardrails, then hands off to the Auto Router
  • • The response returns in the normal OpenAI format

Decision

  • • Only the classification request goes to D3-mini
  • • SIMPLE and MEDIUM map to gpt-4o-mini; COMPLEX and REASONING to gpt-4o
  • • A timeout after 15 seconds falls back to gpt-4o

Telemetry

  • • Classifier and completion calls are both traced
  • • Spans and metrics carry no prompt content
  • • Validate tier accuracy on representative prompts before relying on savings
