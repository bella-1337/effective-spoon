Optional Langfuse profile

Extra LLM trace UI, datasets, and evaluations fed by LiteLLM's langfuse_otel callback

Trace path

  • • LiteLLM adds langfuse_otel only when the profile runs
  • • A trusted hook replaces user and session IDs with HMAC pseudonyms
  • • Prompt and response content is never exported

Datastores

  • • PostgreSQL for state, ClickHouse for traces, Redis for queues
  • • MinIO stores events and media behind its own Traefik host
  • • All Langfuse values live in .env.optional

Access limits

  • • Public sign-up is disabled; one initial administrator
  • • trace_user_id is not an authorization boundary
  • • Keep the shared project restricted to administrators and operators
